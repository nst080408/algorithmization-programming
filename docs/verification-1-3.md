# Проверка энергии пружины

Проверено 17.11.2026. Конфигурация Release, .NET SDK 10.0.404. Всё решение собрано без предупреждений и ошибок. Каждая строка таблицы соответствует отдельному запуску программы с указанными входными данными.

Эталон рассчитан независимо с 50 значащими цифрами. Значения программы выводятся с десятью знаками после десятичного разделителя. Допуск для округлённого вывода: `5,01 · 10⁻¹¹`. Все перечисленные результаты совпали с эталоном в пределах допуска.

| Ввод k, Н/м | Ввод x, м | Вывод E, Дж |
| --- | --- | ---: |
| `200` | `0.1` | 1.0000000000 |
| `200` | `0,1` | 1.0000000000 |
| `250` | `0` | 0.0000000000 |
| `1` | `1` | 0.5000000000 |
| `3.5` | `0.2` | 0.0700000000 |
| `3,5` | `0,2` | 0.0700000000 |
| `1000` | `0.05` | 1.2500000000 |
| `1e2` | `2e-1` | 2.0000000000 |
| `400` | `0.1` | 2.0000000000 |
| `200` | `0.2` | 4.0000000000 |

Проверены отсутствие растяжения, дробные величины, оба десятичных разделителя и экспоненциальная запись. При одинаковом растяжении увеличение жёсткости с 200 до 400 Н/м удваивает энергию. При жёсткости 200 Н/м увеличение растяжения с 0,1 до 0,2 м увеличивает энергию в четыре раза.

Все входные данные в таблице соответствуют ограничениям `k > 0`, `x >= 0`. Сантиметры автоматически в метры не переводятся: программа запрашивает растяжение в метрах.
