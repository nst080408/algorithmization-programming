Проверено 16.11.2026 на .NET SDK 10.0.404. Решение собрано в конфигурации Release: **0 предупреждений, 0 ошибок**. Проверки ниже выполнены запуском собранной программы с вводом через стандартный поток.

## Сверка с Excel

В [verification.xlsx](verification.xlsx) сохранены исходные данные и формулы. Файл открыт и пересчитан в Microsoft Excel 16.0. При `x = 2` Excel получил **2,7338095116624275**. Программа вывела **2,7338095117** после округления до десяти знаков. Расхождение около `3,76 · 10⁻¹¹` объясняется округлением вывода.

Пересчёт Excel также проверен изменением `x` на `0`: результат стал `0`. После возврата `x = 2` восстановился исходный результат. В файле оставлены исходные данные варианта.

Для повторной проверки вручную заполнить в Excel: `C7 = 3`, `C8 = 1`, `C9 = 2`, `C10 = 2`. Числитель в `C13`, знаменатель в `C14`, результат в `C15`:

```text
C13: =C7*C10^2+(3/5)*C8*ABS(C10)
C14: =C9+SQRT(C10^2+4)
C15: =C13/C14
```

В русской версии Excel функция `SQRT` называется `КОРЕНЬ`. В сохранённом `.xlsx` используются стандартные имена функций, которые Excel отображает на языке установленной версии.

## Дополнительные значения

Для этих проверок использован независимый расчёт с 50 значащими цифрами. Допуск для вывода программы составляет `5,01 · 10⁻¹¹`, поскольку результат печатается с десятью знаками после запятой.

| Ввод x | Вывод y | Результат |
| --- | ---: | --- |
| `2` | 2.7338095117 | Совпадает с округлением |
| `0` | 0E-10 | Совпадает с округлением |
| `-2` | 2.7338095117 | Совпадает с округлением |
| `1.5` | 1.7000000000 | Совпадает с округлением |
| `1,5` | 1.7000000000 | Совпадает с округлением |
| `-1.5` | 1.7000000000 | Совпадает с округлением |
| `-1,5` | 1.7000000000 | Совпадает с округлением |
| `0.1` | 0.0224859551 | Совпадает с округлением |
| `-0.1` | 0.0224859551 | Совпадает с округлением |
| `10` | 25.0859994232 | Совпадает с округлением |
| `␠2␠` | 2.7338095117 | Совпадает с округлением |
| `2e0` | 2.7338095117 | Совпадает с округлением |

Обозначение `␠` в таблице показывает пробел. Ввод с точкой и запятой, отрицательные числа, ноль, пробелы вокруг числа и экспоненциальная запись проверены.

Реальный текст запуска при `x = 2` сохранён в [console-example.txt](console-example.txt). При проверке ввод был перенаправлен в программу, поэтому введённая цифра не отображается в журнале, а приглашение и ответ стоят в одной строке. При вводе с клавиатуры строка завершается нажатием Enter.

## Ограничения

Как в примере методички, предполагается корректный числовой ввод. Обработка пустой строки, текста, бесконечности и переполнения не добавлена. Вещественные вычисления имеют погрешность округления.
